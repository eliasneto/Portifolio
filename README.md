# Portfólio — Elias Neto

Site estático (HTML, CSS e JavaScript, sem build) com os projetos de automação, RPA e integrações.

## Ver localmente

Abra o `index.html` no navegador.

## Publicação

Publicado pelo GitHub Pages a partir da branch `main` (pasta raiz).

## Como adicionar um projeto

Copie um bloco `<article class="project">` em `index.html` e ajuste título, problema, solução, resultados e tecnologias.
Use somente números reais e não coloque IPs, servidores, senhas ou dados internos de clientes.
